# STALE 外部评测记录（2026-11-22）

> 目的：用公开基准验证 `memgov ai-supersede` 的判定质量，替代只看自家样本的口径。
> 数据：`STALEproj/STALE` 的 `T1_T2_400_FULL.json`（400 条专家验证隐式冲突场景，CC-BY-4.0，292 MB，本地 `data/stale/`，不入库）。
> 脚本：`scripts/stale_eval.py`（正样本召回 + 交叉配对负样本假阳性）。

## 一、基准结构

每条记录：`M_old`（旧信念）、`M_new`（后来的观察，**无显式否定**）、`explanation`（如 "location(city) is now Austin"）、三类探测查询。

负样本由脚本构造：把 A 的 `M_old` 与 B 的 `M_new` 交叉配对（不同 uid），预期判 `INDEPENDENT`。这是唯一能测假阳性的办法——基准本身没有负样本。

## 二、结果（deepseek-flash，三视角，票比 ≥0.6）

### 首轮：中文提示词，20 正 / 10 负

| 指标 | 值 |
|---|---|
| 正样本召回（应 SUPERSEDES） | **5.0%**（1/20） |
| 负样本特异度 | 100%（10/10） |
| 假阳性率 | 0.0% |
| 正样本平均置信度 | 0.214 |
| 用量 | 90 次调用，81,198 tokens |

阈值扫描（0.90 → 0.50）：召回 1/20 → 2/20，假阳性始终 0。**降阈值救不回来**。

### 对照：英文提示词，同前 20 条

| 阈值 | 召回 | 假阳性 |
|---|---|---|
| 0.90 | **6/20（30%）** | 0/10 |
| 0.85 | **13/20（65%）** | 0/10 |

60 次调用。多次出现「三票全 SUPERSEDES、置信度 0.88」被 0.90 门槛卡住的情况。

### 真实库：全量 11,165 条，候选上限 1,000，判 42 对

| 指标 | 值 |
|---|---|
| 含冲突词记录 | 1,041（9.3%） |
| 锚点通道候选 | ≥1,000（触顶） |
| 种子通道候选 | ≥1,000（触顶） |
| 进入判定 | 42 |
| **按 0.90 接受** | **0** |
| 用量 | 120 次调用，142,961 tokens |

票比分布：0.0 × 34、0.333 × 4、**0.667 × 2**、**1.0 × 2**。四对判官明确要求取代，全部因置信度 0.77–0.88 被 0.90 拒绝。

阈值扫描：0.90 → 0 条、0.85 → 2 条、0.80 → 3 条、0.75 → 4 条。

## 三、结论

1. **判定逻辑本身没坏**：负样本 0 假阳性；全库有四对票比 ≥0.667 且理由具体（「同一 C11 规则，NEW 更新触发项并收窄审计口径」）。
2. **第一卡点是置信度门槛**：模型给分集中在 0.77–0.88，0.90 是照抄别处的保守值，与本模型分布不匹配。
3. **第二卡点是语言错配**：中文提示词在英文基准上召回 5%，换英文提示词升到 30%（阈值 0.85 时 65%），说明判官需要按文本语言选模板。
4. **口径差异仍在**：STALE 的 ground truth 是「新观察让旧信念不再适用于当前」，包含需要世界知识推理的隐式失效；我们的规则要求「同一属性、不同取值」，因此剩余未召回的多数被判「可共存」——这是**visibility（该不该被检索）与 validity（是否仍为真）混在一起**造成的，不是判定器缺陷。

## 四、下一步建议（按成本排）

1. 阈值按本模型分布标定：0.85（全库接受 2 条、STALE 英文 65%），并保留 0.90 作为可配置上限。
2. 提示词按语言自适应：中文库用中文模板，英文数据用英文模板。
3. 若要以 STALE 为目标达标，需要做 validity/visibility 分离（VALIDMEM 的四态 + intent router），而不是继续调 supersede 判定。

## 五、复跑方式

```bash
cd ~/agentdt/开源项目/memgov
# 需要 MEMGOV_AI_API_KEY / --ai-base-url / --ai-model
/usr/bin/python3 scripts/stale_eval.py --positives 20 --negatives 10 \
  --ai-base-url https://oneapi.xgd.com/v1 --ai-model deepseek-flash \
  --out runs/stale-eval-20-10.json
```

注意后台 shell 里的 `python3` 可能解析到没有 PyYAML 的那份，一律写绝对路径 `/usr/bin/python3`。
